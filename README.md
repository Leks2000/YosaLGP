# Йося (Yosa) — лендинг умного счётчика калорий с ИИ-котом

## Обзор проекта
- **Название**: Йося (Yosa)
- **Цель**: Промо-лендинг мобильного приложения «Йося» — счётчика калорий с ИИ-котом, который считает КБЖУ по голосу/тексту.
- **Стек**: React 19 + Vite + TailwindCSS v4 + Motion (Framer Motion) + Express (SSR-статик + API `/api/estimate` через Gemini).

## Реализованные фичи
- **Hero с премиальной ЗАГЛУШКОЙ ВИДЕО** в рамке iPhone (Dynamic Island, статус-бар iOS, стеклянная кнопка play с пульсацией, таймлайн-полоска). Карусели скриншотов в hero больше нет.
- **Арт-иконка приложения** как бейдж-тег в hero.
- **7 рекламных кадров (ad_01..07) раскиданы по смыслу** в соответствующих секциях, а не одной каруселью:
  - стрик/бейджи/календарь (`ad_01`, `ad_03`, `ad_07`) → BadgesGallery (ряд из 3 кадров);
  - виджет (`ad_04`) → WidgetSandbox (приклеенный кадр);
  - настройки и цели (`ad_02`, `ad_06`) → GoalsCalculator (два приклеенных кадра).
- **Интерактивный оценщик КБЖУ** (CalorieEstimator).
- **Сетка возможностей** (Features).
- **Калькулятор целей BMR/TDEE** (GoalsCalculator).
- **Арт-вселенная Йоси** (ArtGallery) — банка Йося, киви, фастфуд + кинематографичный баннер с космонавтом и CTA.
- **Секция «Ты ещё не скачал?»** (DownloadNudge) — 5 реальных фото кота с игривыми репликами («О, привет! Ты ещё не скачал?», «позор», «как так?», знакомство, заигрывание).
- **История Йоси** (CreatorStory) — реальные фото кота создателя в разнобой.
- **FAQ-аккордеон** с фоновым артом «грязного кота».
- **Двусторонние scroll-анимации**: плашки появляются при прокрутке вниз и плавно исчезают при прокрутке вверх. У плашек уникальные варианты (slide/zoom/rotate/blur).
- **Двуязычность** RU/EN. Кнопка переключения: на русском пишет «АНГЛИЙСКИЙ», на английском — «RUSSIAN».
- **SEO**: title/description/keywords, Open Graph, Twitter Card, JSON-LD `SoftwareApplication`, `robots.txt`, `sitemap.xml`.

## Функциональные точки (URI)
- `GET /` — основной лендинг (SPA).
- `GET /api/health` — health-check, возвращает `{ status, time }`.
- `POST /api/estimate` — оценка КБЖУ по описанию блюда. Тело: `{ "food": string, "language": "ru"|"en" }`. Требует `GEMINI_API_KEY` (есть mock-фолбэк).

## Изображения и ассеты
- Все изображения сконвертированы в **WebP** для быстродействия (`src/assets/images/`).
- 7 рекламных скриншотов: `ad_01..ad_07`.
- Реальные фото кота: `cat_photo_1..5`.
- Арты: `art_yosa_can`, `art_kiwi`, `art_rem_mcd`, `art_astronaut`, `art_dirty_cat`.
- Иконка приложения → favicon/apple-touch-icon/og-image в `public/`.

## Запуск локально
```bash
npm install
# .env: GEMINI_API_KEY=...
npm run dev          # dev (Vite middleware)
npm run build        # прод-сборка (dist/ + dist/server.cjs)
pm2 start ecosystem.config.cjs   # прод через PM2 на :3000
```

## Деплой
- **Платформа**: Express SSR-статик (Node). Запуск: `node dist/server.cjs`.
